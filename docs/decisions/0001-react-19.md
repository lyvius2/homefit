# ADR 0001 — React 19 로 전환

- 날짜: 2026-11-01
- 상태: 승인 (소유자)
- 관련: 설계서 Section 2 스택, AGENTS.md Section 2

## 배경

설계서 초안은 React 18 을 고정했다. M1 에서 설치해 보니 React 18 에 묶이는 순간
`@react-three/fiber` 8.x, `@react-three/drei` 9.x, `react-konva` 18.x 처럼 유지보수가 끝난 메이저에 머물러야 하고,
이 버전들은 현재 `three` 0.187 과 조합이 검증되지 않았다. M4(Konva 도면 에디터)·M5(R3F 배치 에디터)에서 깨질 위험이 크다.

## 결정

React 19 를 쓴다. 함께 올라가는 패키지:

| 패키지 | M1 초기 | 전환 후 |
|---|---|---|
| react, react-dom | 18.3.1 | 19.3.1 |
| @react-three/fiber | 8.18.0 | 9.8.2 |
| @react-three/drei | 9.122.0 | 10.7.9 |
| react-konva | 18.2.16 | 19.3.2 |
| @types/react, @types/react-dom | 18.3 | 19.3 |

## 영향

- M1 시점에는 `islands.tsx` 의 `createRoot` 뼈대뿐이라 코드 변경 없음. tsc·eslint·vitest·vite build 모두 통과.
- React 19 에서 바뀐 점 중 이 프로젝트에 닿는 것: `forwardRef` 불필요(ref 가 prop), `useEffect` 정리 타이밍 엄격화, R3F 9 의 `Canvas` 이벤트 타입. 에디터 구현 시 R3F 9 / react-konva 19 문서를 기준으로 작성한다.
- 설계서 Section 2 스택 표와 AGENTS.md Section 2 표의 "React 18" 을 "React 19" 로 갱신했다.
